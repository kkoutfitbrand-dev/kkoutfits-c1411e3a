# One-click event theme system

## Goal
Turn **Admin → Sales** into a library of ready-made campaigns. An admin can preview an event and press **Apply Theme** to publish its wording, dates, discount messaging, banner treatment, colors, decorations, and campaign sections across the storefront.

The screenshot error is caused by the new sale storage not existing yet. The staged database change will be extended for themes and will apply when this draft is accepted.

## Ready-made themes

- Indian festivals: Diwali, Pongal, Holi, Eid, Onam, Navratri, Independence Day
- Retail events: Big Sale, End of Season, Clearance, Black Friday, New Year
- Each preset includes campaign name, title, subtitle, promotional text, suggested discount, theme palette, decorative treatment, and default artwork presentation.
- Admin can still customize every field and upload a replacement banner.

## Admin experience

1. Open Sales and browse all event templates.
2. Preview each theme card and its campaign copy.
3. Press **Apply Theme**.
4. Set or confirm dates and discount in a compact publish dialog.
5. Save once; the selected event becomes the only enabled campaign and updates the storefront immediately.
6. Existing campaigns remain editable, disableable, and removable.

## Website coverage

The active theme wraps the public storefront and updates semantic campaign colors, sale banner, countdown strip, promotion section, sale labels, and event decorations. Product pricing, category data, checkout, and normal site functionality remain unchanged. If there is no active campaign, the standard KK Outfits design remains in place.
